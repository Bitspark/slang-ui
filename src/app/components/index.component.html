Slang editor

A visual editor for Slang operators, served by the Slang daemon. Build a program by placing operators and connecting their typed ports, then run it against the daemon.

Create an operator

Type a name in New operator on the left and confirm. The new operator opens in the editor. Existing operators are listed above it — select one to open it. To bring in work from elsewhere, choose a workspace file and press to import it.

Build the program

In the editor, add operators from the list on the left. Drag from an output port to an input port to connect them. Ports are typed, so a connection is only accepted when the types match; generics and properties are configured on the selected operator. Use and to switch between the visual graph and the YAML definition — both edit the same operator.

Run it

Press to save, then to start the operator. Send values to its input port and the daemon returns the output below. Press to stop it again. downloads the operator definition.
